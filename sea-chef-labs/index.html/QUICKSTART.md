# ⚡ Quick Start Guide - Sea Chef Labs

## 🚀 Get Running in 2 Minutes

### Step 1: Install Node.js
Download from: https://nodejs.org (LTS version)

### Step 2: Open PowerShell
```powershell
# Navigate to project folder
cd C:\Users\craig\Downloads\sea-chef-labs
```

### Step 3: Install & Run
```powershell
npm install
npm run dev
```

### Step 4: Open Browser
Go to: **http://localhost:5173**

**That's it! You're running!** 🎉

---

## 📱 View on iPhone

### Option A: Same WiFi (Easiest)
1. Find your computer's IP:
   ```powershell
   ipconfig
   # Look for IPv4 Address (e.g., 192.168.1.100)
   ```
2. On iPhone Safari, go to:
   ```
   http://192.168.1.100:5173
   ```

### Option B: Deploy Online
```powershell
npm install -g vercel
vercel
```
Then open the URL on your iPhone!

## 🆘 Troubleshooting

**"npm not found"** → Install Node.js  
**"Port in use"** → Close other terminals or use different port  
**"Can't see on phone"** → Check firewall, use correct IP
