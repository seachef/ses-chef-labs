# NEPTUNE

NEPTUNE is an edge-to-edge ocean-art crypto observatory with a read-only paper feed. The root opens the NEPTUNE scene; the existing private portfolio and research tools remain available from its footer.

The scene uses the approved Neptune artwork, animated atmospheric rain and light, optional ocean sound, and compact code / paper ledger / event windows. Mobile uses tabbed windows. Reduced-motion preferences are respected.

Weather is decorative, never a market signal. Coin flares require new, fresh server events. No real-money orders or wallet signing are added. Empty, stale and offline feeds never fabricate fills or profit.

## Tests

`node --test preview/research-desk/status.test.mjs`

## Naming compatibility

Visible application branding is NEPTUNE. Existing storage keys and integration identifiers are retained to preserve saved user data. The repository URL still uses `ses-chef-labs` until its owner renames it in GitHub Settings; repository administration is not available through the current connection.

## Run locally

From the repo root:

```bash
python -m http.server 8000
```

Then open:

```text
http://localhost:8000/index.html
```

## Free hosting with GitHub Pages

1. Go to the GitHub repo.
2. Open Settings > Pages.
3. Set Source to **Deploy from a branch**.
4. Choose the `main` branch and the root folder `/`.
5. Save.
6. Your site will be published at:

```text
https://seachef.github.io/ses-chef-labs/
```
